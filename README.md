# 🐍 Python Problem Solving Library

A comprehensive collection of Python programming problems, practical examples, and algorithm implementations organized by topic. This repository is designed to strengthen programming fundamentals, logical thinking, and problem-solving skills through hands-on practice.

## 📚 Topics Covered

| # | Topic | Description |
|---|---|---|
| 01 | 1D Arrays | Array operations, traversal, searching, and manipulation |
| 02 | 2D Arrays & Matrices | Matrix operations and multidimensional arrays |
| 03 | Conditional Statements | If, elif, else, and decision-making problems |
| 04 | Loops | For, while, and nested loop problems |
| 05 | Functions | Function creation, arguments, and return values |
| 06 | Data Structures | Lists, tuples, sets, dictionaries, and more |
| 07 | Dynamic Memory Concepts | Object references, memory management, and mutability |
| 08 | File Handling | Reading, writing, and managing files |
| 09 | Input-Output Operations | User input, output formatting, and operators |
| 10 | Number Theory & Mathematics | Prime numbers, factorials, GCD, LCM, and mathematical problems |
| 11 | Pattern Printing | Number, character, and star patterns |
| 12 | Recursion | Recursive functions and problem solving |
| 13 | Searching & Sorting | Linear search, binary search, and sorting algorithms |
| 14 | Strings | String manipulation and character operations |
| 15 | Pointers & References | Python object references and memory concepts |
| 16 | Structures & Unions | Understanding similar concepts through Python classes and data structures |
| 17 | Competitive Programming | Programming challenges and algorithmic problem solving |
